# Hangman Spelling Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A kid-friendly static PWA hangman game (custom word lists + random common nouns, Swedish/definition/classic clues) for English spelling practice on a phone.

**Architecture:** Plain static files, no build step: `game.js` is pure logic (no DOM) tested with Node's built-in test runner; `app.js` wires DOM/localStorage; `index.html` holds all screens as sections; service worker + manifest make it an offline-installable PWA. Mirrors the sibling `imposter/` app.

**Tech Stack:** Vanilla HTML/CSS/JS (ES modules), Node built-in `node:test` for tests, no dependencies.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-09-21-hangman-design.md` — follow it.
- 8 wrong guesses max; on-screen A–Z keyboard only (never trigger the native keyboard).
- Words: single words, letters A–Z only (stored uppercase).
- Clue modes: `"sv"` (default), `"def"`, `"classic"`; missing data ⇒ fallback to classic for that round.
- localStorage keys: `hangman.clueMode`, `hangman.lists`, `hangman.listProgress`, `hangman.recentWords`, `hangman.difficulty` — every read wrapped in try/catch with defaults.
- Kid-friendly visuals: bright cheerful palette, big rounded touch targets, playful (system) rounded font stack, emoji accents, gentle animations, friendly (not scary) hangman figure. Mobile-first (~380px), no horizontal scroll.
- UI text in English. No accounts, no network calls except loading own static files.
- Commit after each task; messages end with the Claude Fable 5 co-author line.

### Task 2: Word selection + clue resolution in `game.js`

**Files:**
- Modify: `game.js`
- Test: `tests/selection.test.js`

**Interfaces:**
- Produces:
  - `pickWord(pool, recent, rng) -> entry` — pool is array of word entries `{en, sv?, def?|hint?, level?}`; avoids entries whose `en` is in `recent`; if all recent, ignores history. `rng` defaults to `Math.random` (injectable for tests).
  - `pickFromList(words, solvedEns, rng) -> {entry, reset}` — picks an unsolved entry at random; when every word is solved returns `reset: true` and picks from the full list.
  - `resolveClue(entry, mode) -> {mode, text}` — `"sv"` uses `entry.sv`, `"def"` uses `entry.def ?? entry.hint`; missing ⇒ `{mode: "classic", text: ""}`; `"classic"` always classic.
  - `filterByLevel(pool, difficulty)` — `"easy"|"medium"|"hard"` map to level 1/2/3, `"mixed"` returns all.
